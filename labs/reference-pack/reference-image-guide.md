# Solace Radiance Serum — Reference-Image Guide

Use this guide in **Lab 7 (Text-to-Image with reference images and styles)** to
obtain and prepare **one** clear reference image that steers your generated
lifestyle scene. A reference image guides the composition and subject of a
text-to-image result, so a clean, relevant input gives a more on-brand output.

## Step 1 — Get an image you are authorised to use

Choose **one** of these (in order of preference for this course):

1. **Generate a concept image.** Use the Firefly web app (or any text-to-image
   tool) with a prompt from the [prompt-sheet](prompt-sheet.md), for example:
   > a calm spa-like bathroom shelf with soft towels and eucalyptus, warm cream wall, soft natural daylight, minimalist premium skincare lifestyle, empty space for a product
   This is the safest option — the image is your own AI-generated concept.
2. **Photograph your own** shelf, surface or setting on a plain background. Only use
   a scene and objects you are free to reproduce.
3. **Use an openly licensed image** (for example CC0) and keep a note of the source
   and licence.

> Do **not** download a brand's campaign image or a stock photo you have not
> licensed — that is someone else's copyrighted image.

## Step 2 — Prepare the image to steer a clean result

- **Match the composition you want** — if you need room for the product on the
  right, use a reference with clear space on the right.
- **Keep it uncluttered** — a simple scene steers better than a busy one.
- **Match the light** — pick or make a reference lit from the **left**, like your
  hero bottle, so the scene and product will composite together.
- **On-brand colours** — warm creams, soft stone and muted botanical green suit
  Solace (see the [style-notes](style-notes.md)).
- **Reasonable resolution** — around 1024 px on the long edge or more; sharp, not blurry.

## Step 3 — Use it

In **Lab 7**, attach the prepared image as the **reference / composition** input in
the generate panel (Photoshop's generate workflow or the Firefly web app), set the
content type to **Photo** and choose a matching **style**, then generate and compare
how much the reference changes the result versus text alone. Pick the scene that is
most on-brand and leaves space for the product.

## Optional — style vs reference

Try the same prompt with the reference **on** and **off**, and with different
**style** presets, so you can feel the difference between steering by a reference
image and steering by style controls. Real work usually uses both together.
